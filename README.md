## 채워 넣는 방법

1. `[대괄호]` 글자를 내 내용으로 바꿉니다. (대괄호까지 지우기)
2. 끝낸 할 일은 `- [ ]`를 `- [x]`로 바꾸면 체크 표시가 됩니다.
3. 날짜별 기록은 표 맨 아래에 `| 11/19 | 그날의 한 줄 |` 형식으로 한 줄씩 추가합니다.
4. 팀원이 늘면 팀 표에 `| 이름 | 역할 |` 줄을 추가합니다.
5. `project-note.html`도 같은 `[대괄호]` 칸이 있으니 함께 바꾼 뒤 커밋합니다.
